# 📘 AI Data Training Portfolio — João Candido

Bem-vindo ao meu portfólio profissional como **AI Data Trainer**, **Content Reviewer** e **Linguistic Content Specialist**.  
Este repositório reúne exemplos práticos de escrita, revisão, análise crítica e criação de prompts — competências essenciais para o treinamento de modelos de Inteligência Artificial (LLMs).

Meu objetivo é demonstrar domínio avançado da língua portuguesa, capacidade analítica, atenção a detalhes e versatilidade textual.
